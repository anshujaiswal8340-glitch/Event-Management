# EventOne — Full-Stack Event Management System

Discover, register, check in, and review events using a modern full-stack application built with Node.js, Express, React, MongoDB, and Socket.IO.

## Key Features

### Customers
* Browse & discover upcoming events
* Register for events instantly
* Download branded PDF tickets with embedded QR codes
* Post event reviews and ratings
* Full dark mode support

### Organizers
* Create and manage custom events
* View real-time participant lists
* Export attendee data as CSV
* Real-time QR check-in via Socket.IO
* Live event analytics and attendance statistics

### Admin
* Approve or reject event submissions
* Manage homepage recommendation engine
* Monitor platform-wide statistics
* Global toast notifications and responsive UI dashboard

## Tech Stack

* **Backend:** Node.js, Express.js, MongoDB (Mongoose), JSON Web Tokens (JWT), Socket.IO
* **Frontend:** React 18, Vite, Tailwind CSS, React Router, Axios
* **Tooling:** ESLint, Prettier, Nodemon, PostCSS, jsPDF, html2canvas
